User flow

Review the behavior

  1. Entry: Supplier Manager opens a selected buyer's WIP planner.
  2. Action: Click the insight action on a production-stage card.
  3. Response: Keep existing guidance/manual content and add an independent overdue area.
  4. Decision: Show current or historical stage events only when a stage date rule produces an overdue event.
  5. Success: Review PO, stage, date, and days late; multiple stage events remain separate.
  6. Empty: Omit the overdue area when no event is calculable.
  7. Recovery: Switch scenario or stage without changing WIP source data.

Rules represented

  • Completion date vs plan when completed; otherwise report date vs plan.
  • Missing plan date is not evaluated.
  • CRD-only lateness is not a stage-overdue event.
  • Historical overdue stays with its original stage.
